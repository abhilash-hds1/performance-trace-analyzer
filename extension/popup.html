Perf AI

This extension lives in DevTools, not as a toolbar popup.

  1. Press F12 on any tab to open DevTools.
  2. Click the Perf AI tab (use the » overflow if hidden).
  3. Set the API base URL, then import a trace or start a recording.

"Can't read or change site's data" is expected: this extension uses chrome.debugger, not page-level access.
